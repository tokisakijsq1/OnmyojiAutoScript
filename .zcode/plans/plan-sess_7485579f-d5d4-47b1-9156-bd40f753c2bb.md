# 结界挂卡 · 星级优先排序功能计划(已获批准)

## 前置说明
前端 OASX 无需任何改动:args_view.dart 的 _form() 按 type 分发渲染,string 类型自动渲染为 TextFormField 并防抖提交。只需后端 pydantic 字段 + i18n 文案。

## 修改内容

### 1. `tasks/KekkaiActivation/config.py`
`ActivationConfig` 新增 `card_sort_order: str = Field(default='', description='card_sort_order_help')`。

### 2. `tasks/KekkaiActivation/utils.py`
新增 `parse_card_sort_order(rule: str) -> list[CardClass]`:去空格/换行/“星”字 → 按 `>` 分割 → 仅接受 斗鱼/太鼓 3~6 星,非法项丢弃记 warning,空则返回 `[]`。

### 3. `tasks/KekkaiActivation/script_task.py`
- 从 `screening_card()` 拆出 `_select_card_class()`(切类型下拉)与 `_confirm_card()`(确认挂卡循环),默认路径行为不变;
- 新增 `_select_card_by_order()`:按优先级分组(连续同类型),逐组切下拉、逐屏滑动、`match_all_any` 匹配组内星级模板,命中组内最高优先级卡即返回 RuleClick;`I_AA_SWIPE_BLOCK` 滑到底或 20 次滑动上限终止;所有组未命中返回 None;
- `screening_card()` 开头:配置非空且解析成功 → 尝试排序选卡;命中则确认挂卡后返回;未命中记日志回退默认模式(OCR 收益最大 + `_card_not_found` 原逻辑不动)。

### 4. i18n(两处)
- `module/config/i18n/zh-CN.json`、`assets/i18n/zh-CN.json` 各加 `card_sort_order` / `card_sort_order_help` 文案。
