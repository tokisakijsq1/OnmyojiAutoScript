# MainStory 主线剧情

自动推进主线剧情：从庭院的三点入口图标进入剧情 → 在剧情里一路点"跳过 / 对话 / 探查 / 战斗" →
回庭院后继续下一段，直到庭院不再出现入口图标。剧情里的战斗复用通用战斗（点准备 / 切自动 / 胜负 / 结算），
**战败即结束任务**。

## 流程

1. **run() → _advance()**：先看启动时是否已经身在剧情中（上次异常中断 / 手动点了入口），是就先把这一段走完；
   否则回庭院找入口。
2. **庭院找入口**：入口图标（金环 + 三颗白点）连续可见 1.5 秒才点；连续 5 秒不出现才认定"剧情全部做完"
   （下一段的入口可能延迟弹出）。入口点了却"进剧情后一下都没点就回了庭院"连续 3 次 → 结束任务。
3. **剧情循环 _story_loop()**：每轮重新截图识别，按下面的优先级**只做一件事**，然后回到开头：

   | 顺序 | 处理 | 说明 |
   |---|---|---|
   | 0 | 剧情跳过链 | 确认跳过 → 动画跳过 → 对话跳过；始终先于刚点返回后的退出确认 |
   | 1 | 退出确认弹窗 | 仅在没有可见跳过按钮、且刚点过返回时处理（新旧两版确定按钮并列识别） |
   | 2 | 其他剧情按钮 | 探查 → 战斗 → 剧情对话三点 → 问号推进 |
   | 3 | 通用"获得奖励"浮窗 | `ui_reward_appear_click` |
   | 4 | 战斗 | 识别到准备页 / 战斗中 / 结算 → 通用战斗流程 |
   | 5 | 庭院 | 连续 2.5 秒可见（且过了 3 秒进场宽限）→ 本段结束 |

   - **跳过链最优先**是用户规则：即使刚点过返回并处于退出确认等待窗口，只要出现确认跳过 / 动画跳过 / 对话跳过，就先处理跳过；只有没有可见跳过按钮时才检查退出确认。对话和动画播放中左上角返回键无效，必须先走完跳过。
   - 庭院对话（跳过按钮叠在庭院画面上、入口图标仍在）交给剧情循环，此时**不去点入口**，也不把庭院上的
     三点当成剧情对话按钮。
   - 顶部聊天播报横幅（区域 `435,61 ~ 1083,108`）浮在按钮上层：从庭院进入剧情后，命中框碰到这块区域的
     按钮一律**不点**（点了会误触播报），按“没看见”交给空等 / 返回退路（2026-11-25 用户要求）。
   - 点了战斗按钮 → 转场进准备页 → `run_general_battle`（点准备 → 等齿轮 → 切自动 → `battle_wait` 等胜负
     → 结算点击）。任务中断后恢复时若已在战斗中 / 结算，直接走等待结算。
     **进战斗前先等准备页/战斗界面真正出现（最多 20 秒）**：剧情→战斗转场实测约 7 秒，而通用
     `battle_before` 只等 5 秒，转场没走完就进去会在准备页上超时，超时兜底的切自动又被准备页左下角
     "预设"按钮骗过齿轮 OCR（误判已开打），最终 `GameStuckError` 重启游戏（2026-11-24 小号5 实机）。
4. **退路**：连续 `ms_idle_timeout` 秒没有任何可识别按钮、**且画面静止**时直接点左上角返回退出本段剧情，回庭院后入口还在就重新进入。相关保护：
   - 画面还在变（过场 / 转场在播）不计入空等，也不点返回——没有跳过键的长过场不会被误判卡住；
   - 连续 4 轮“静止且无按钮”（约 60 秒）仍退不出去 → **不抛卡死异常**，而是先按失败间隔排期、再让导航
     兜底回庭院。原因：抛 `GameStuckError` 会重启并原地重试，同一个未知画面连撞三次就是 `exit(1)` 杀掉
     整个实例；导航也认不出时抛 `GamePageUnknownError` 走标准重启，但排期已设好，不会原地重试；
   - 单段剧情超过 30 分钟（界面来回变但剧情不推进）同样按“退不出”处置；
   - 点返回退出累计达到 `ms_escape_limit`（默认 3）→ 结束任务。凡出现过“退不出”，本次运行一律按失败收尾。
5. **收尾**：正常做完按成功间隔排期；战败 / 退不出 / 入口无响应 / 段数到顶按失败间隔排期并推送通知。
   现场截图存 `log/screenshots/MainStory/`，遇到没见过的剧情界面据此补素材。

## 连点保护与点击容错

主线是"点三点 → 出对话 → 点跳过 → 回场景 → 再点三点"的连续点击，`device.click_record`（最近 15 次点击）
里**两个按钮各 6 次就会触发** `GameTooManyClickError`。本任务每次点击时记录"当前可见按钮组合 + 位置"作为
状态签名：相邻两次点击之间状态变了（= 点击生效）且记录已攒到 9 条，就清一次记录；**状态没变的重复点击
不清**，"点了没反应"的保护照常生效（第 10 次被拦）。

在此基础上（2026-11-24 用户要求）加了**点击容错**，防止"认为点了、实际游戏没收到"：

- 每次点击后等 0.5 秒（`CLICK_SETTLE`）再进入下一轮识别，避免在旧画面上重复点击；
- 同一按钮在**同一画面状态下**连点 3 次（`CLICK_RETRY_LIMIT`）画面仍没变 → 判定点击无效，
  **拉黑该按钮组合**：当作没看见，让奖励 / 战斗 / 庭院 / 空等分支接手（空等后直接返回），
  状态一变立即解禁；
- 拉黑的按钮还叠在庭院上时（点不动的庭院对话）按 `stuck` 收尾交导航兜底，否则外层会无限重进剧情循环。

### 半透明图标识别

透明 / 半透明底板会让 RGB 模板混入底图颜色，mask 本身不做动态背景消除。本地离线样本验证采用剧情上下文门：保留问号原模板并扩大搜索 ROI；剧情对话三点改为内容区 ROI；两者只有同时匹配左上圆形返回键（>0.85）和剧情专用对话气泡（>0.83）才进入可点击 / 剧情启动判定。问号的 9 张正样本全部命中（最低非来源分 0.921），对话三点 2/2（0.985、1.000），721 张历史截图联合判定零误报。问号裸匹配在式神派遣帮助弹窗的碎片卡问号得 0.896；剧情专用 HUD 气泡本身在 11 张剧情样本为 0.836~1.000，在 722 张历史截图中的最高分为 0.598。全屏三点相似 UI 会误命中；剧情内三点通过 HUD 过滤后 0/721。入口图标仍用独立庭院 ROI，三点也不能裁成极小内核裸搜。本节记录的离线样本均为当前验证结果，尚未覆盖 HUD 被遮挡时的识别以及更多章节的三点外观；上述识别改动未做实机复测。


1. **素材多为单样本**：对话跳过、动画跳过键、探查都只有一张来源图（三点各两帧）。问号推进按钮有
   2026-11-24 实机的 4 帧样本（含三个旋转相位），但都在同一场景；探查 / 战斗 / 问号图标在其他章节
   可能是别的图案；遇到时走"退路"并存现场截图，按截图补模板。
2. **入口图标位置浮动很大**：实测 x 617~892、y 217~285，搜索区已放成庭院中部一大片 `(480,150,620,220)`。
3. **点返回后的退出确认弹窗没有见过实物**：现在用通用确定按钮（新旧两版）兜，样式不同则退不出，
   60 秒后走"退不出"处置（排失败期 + 导航兜底）。
4. **"画面静止"帧差阈值 2.5 是离线标定的**：同剧情场景两个对话节拍之间 1.02、语料同画面截图对 75 分位 1.42、
   镜头 / 人物在动 ≥4。阈值偏小只是让卡住的画面多等一会儿（最坏到 30 分钟上限），偏大才可能打断过场。
5. **庭院对话的"跳过"之后接什么**（直接回庭院还是进场景）未见实物，两种情况状态机都能接。
6. **实机（2026-11-24）**：小号5 首跑两段剧情完整走通（54 / 72 次点击），第三段撞到当时无模板的问号图标 →
   退路 3 次正确收尾。小号4 二跑（重启带新代码后）问号按钮在 4 个不同位置全部点到、预设切换 + 战斗胜利 +
   结算全通。据此修了战斗转场 bug、补问号模板；**3 次点击容错、阈值 0.8 尚未实机复验**，本次移除剧情滑动后亦待实机复核，
   改代码后 oas 进程要重启才生效（sys.modules 缓存）。
7. 实机复核清单：日志里 `Click story entry` / `Story loop end` / `Story idle` 的节奏；`log/screenshots/MainStory`
   是否有新的 `idle` 截图；连点保护是否误触发（不应出现 `GameTooManyClickError`）；切自动是否再失败；问号与三点跨背景匹配仍需实机确认。

## 离线仿真

`log/mainstory_build_20261124/sim_story.py`（`log/` 不入库）：用**真实的 `ScriptTask` + 真实规则类 + 用户截图 +
假设备**跑状态机，虚拟时钟代替真实等待，假设备的连点保护规则与 `module/device/device.py` 一致。
已验证场景包括：全流程、战败、静止空等后直接走返回退路（无剧情滑动）、退不出（含导航失败）、连点保护生效 / 放行、入口无响应、启动时已在剧情中、启动时停在探索地图不误点、庭院对话状态启动、长过场、时长到顶、缓慢漂移画面、返回确认与跳过并存、问号推进场景。
运行：`toolkit/python.exe log/mainstory_build_20261124/sim_story.py`（约 3~4 分钟）。
