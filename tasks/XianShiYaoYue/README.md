# 现世妖约（XianShiYaoYue）

十周年现世妖约 LBS 线下庆典活动的自动挑战。

## 流程

1. （可选）执行任务前切换御魂（组件 `SwitchSoul`，在庭院式神录中完成）
2. 庭院右侧点击 `线下庆典` 进入活动页
3. （可选）点击左侧 `商店` 灯笼，OCR 识别绿框位置是否有 `现世祝福`（100 勾玉），有则点击购买，已购买自动跳过；随后点 `活动` 灯笼切回活动页
4. 循环 N 次（`battle_count` 可在 UI 配置）：
   - 点击 `寻找队伍` → 组队界面点击 `自动匹配`
   - 等待匹配：若协战队伍出现（不消耗体力的）`挑战` 按钮则点击；匹配失败会自动重试（最多 3 次）
   - 进入战斗后复用 `GeneralBattle` 通用战斗：点准备 → 战斗 → 结算点击一次退出（不连点，点一次确认跳转）
   - 回到活动页后开始下一轮
5. 结束后返回庭院，调度器 `set_next_run`，日志输出战斗/胜利统计

## 其他

- **直接组队挑战（可选）**：开启虚拟定位并定位到活动城市后，可勾选"直接组队挑战"，
  循环变为 组队挑战 → 战斗 → 下一轮，跳过寻找队伍/自动匹配，且等待界面一定会出现挑战按钮；
  点组队挑战会弹出"队伍公开权限"弹窗，脚本会勾选"所有人"再点创建
- 每轮战斗前 OCR `挑战次数: x/y`（右下角），次数用尽自动提前结束
- 素材截图取自 1280x720；活动图标为动态立绘，若识别率下降请用工具重新截图校准
  （`线下庆典`/`挑战` 阈值放宽至 0.75）
- 协战队伍的深色菱形"挑战"按钮在现有素材库中无可复用模板（探索/道馆等均为浅色样式），
  模板裁剪时已避开底部体力图标区域，消耗体力与免费两种版本均能匹配
- 左侧"活动"灯笼在活动页（金色）和商店页（灰暗）渲染状态不同，两个模板都在
  `xy_goto_activity.png` / `xy_goto_activity_2.png`，页面链接和脚本里都会同时尝试
- 庭院入口图标（线下庆典）位置随账号右侧图标数量浮动、小猫立绘会轮换：
  两种猫样式模板 + 整个右栏搜索范围（复用 FloatParade `fp_access` 的 roiBack 模式），
  匹配不到时自动点击右栏底部的刷新按钮换一批；入口/刷新仅在庭院时点击，点击后等页面过渡防连点
- 匹配/排队阶段每轮重置设备卡死检测（`stuck_record_clear`），
  并 OCR 屏幕上方"现世之约 前方约有XXXX排队"横幅：人数存在即排队正常，不触发任务重启；
  人数 10 分钟无变化仅告警；横幅消失后重置 180 秒等待窗
- 活动页/商店页退出必须先点右上角粉色叉再点左上角黄色返回（叉不点则返回无效）；
  粉叉复用通用资产 `I_UI_BACK_RED`（实测两页均可命中），退出逻辑在 `_exit_to_main()`
- 页面注册在 `page.py`（活动页 / 现世商店页），入口挂在 `page_main` 的线下庆典图标上
